Desenvolvi um projeto completo de e-commerce fictício, integrando front-end responsivo com HTML, CSS e JavaScript, além de um banco de dados MySQL para gerenciar produtos, usuários e pedidos. O sistema simulava uma loja virtual com carrinho de compras e autenticação de clientes.

Modelagem 3D para Impressão (Arte 3D)

Realizei um projeto de modelagem 3D para impressão, criando personagens icônicos como Darth Vader. O trabalho envolveu detalhamento de superfícies e ajustes para que o modelo fosse impresso com fidelidade em uma impressora 3D.
